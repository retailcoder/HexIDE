### Added

- **Hovers are drawn as Markdown.** A language server's quick info now shows emphasis, code, lists and links as
  formatted text, with `vb`/`vb6`/`vba` code in the code window's own colours, on a card the theme colours
  (`HoverBackground`, `HoverForeground`, `HoverBorder`, `HoverCodeBackground`, `HoverLink`). A plain-text hover is
  shown as it came. Raw HTML is shown as text, images as their alternative text, and nothing in a hover is fetched
  or run.
